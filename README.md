# El Impostor

Juego de fiesta para jugar con amigos pasando un solo teléfono. No necesita instalación ni servidor: es un único archivo `index.html`.

## Cómo jugar
1. Carga los jugadores (mínimo 3).
2. Elige los temas (vehículos, cine, series, dibujos animados, animales, comida, deportes…).
3. Elige cuántos impostores, si el impostor tiene pista, roles extra (Cómplice, Infiltrado, Bufón) y el cronómetro.
4. Pasen el teléfono: cada uno ve su rol y la palabra (el impostor ve la pista).
5. La app indica quién empieza; debatan con el cronómetro y voten a quién expulsar.

## Abrirlo
- Abre `index.html` en cualquier navegador, o
- Actívalo en GitHub Pages (Settings → Pages → rama `main`, carpeta raíz) y abre la URL en el móvil.

`juego.html` es la misma página sin la cabecera HTML (versión usada para publicarla como Artifact).
